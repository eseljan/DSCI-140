# DSCI 140 Learning Activity Scripts

Each subfolder is one Posit Cloud "learning activity" project. Inside each:

- `<Activity Name>.R` — student version, with instructions and blanks to fill in
- `<Activity Name> Answers.R` — fully worked answer key

## Folders

- `Opening Data Practice/` — read_csv/read_excel/read_dta/read_delim/read_fwf practice, matching the Opening Data unit slides

To add a new activity: create a new folder named after the activity, add the two scripts following the same naming pattern, commit, and push.
